日日練習｜不動產營業員題庫・全題詳解版

一、啟動
1. 將整個 ZIP 解壓縮，所有檔案保持在同一資料夾。
2. Windows 電腦已安裝 Node.js 時，雙擊 start.cmd。
3. 瀏覽器開啟 http://127.0.0.1:6666 。若剛開啟顯示無法連線，重新整理即可。
4. 使用期間保留啟動視窗；關閉它即停止網頁服務。
5. 不需安裝任何 npm 套件、不需登入、不需網路連線。

也可直接雙擊 index.html 開啟。不同瀏覽器對本機檔案的儲存方式不同，長期練習建議固定使用上述網址。直接開檔與網址版的紀錄不會自動共用，可用備份搬移。
其他系統：在資料夾執行 node server.js，再用瀏覽器開啟上述網址。

二、五種練習模式（2026-10-30更新）
1. 全科模擬考：全988題隨機抽100題，滿分100、60分及格。
2. 各章節抽題：10個主要科目各抽10題，混合成100題，60分及格。
3. 單一章節練習：選主要科目，再選全部或原PDF子章節；選10、20、50、100題或全部。
4. 全部錯題練習：重練目前所有待複習錯題，不限制100題。
5. 章節錯題練習：在錯題本選主要科目或子章節，重練所選範圍的全部錯題。

所有模式每題答對1分、答錯0分、不倒扣，題目及選項每回隨機排列。
指定題數不足時僅抽現有題目，同一回不重複。單章及錯題模式以實際題數計分，另顯示正確率，不判定及格。
模擬考及各科均衡抽題正常均為100題；若另換成不足題數的題庫，少於100題時不判定60分及格。
點選選項作答，上一題、下一題或題號皆可導航；交卷前可以清除或更改。
交卷前網頁對話框顯示未作答題數。未作答算0分，與錯題一起加入錯題本。
交卷後可查看當次每題的選項順序、你的答案、標準答案及原PDF連結。

三、進度、分類與錯題
每次選答案及換題即保存。離開或重新整理後，首頁「繼續作答」恢復原題目、順序及答案。
同一使用者同時保留一份進行中練習；開始其他模式前可先交卷，或選「退出本次測驗」捨棄這回作答。退出不計分、不增加歷史或錯題；暫停返回首頁仍會保留進度。
錯題本保留尚未答對的累積錯題。交卷後答對就移出待複習清單，舊歷史仍保留。
題數顯示會隨所選科目與子章節即時更新。沒有錯題時，相應開始按鈕停用。
手機版採單欄，題號區可內部捲動，歷史表格可橫向捲動。

四、歷史與備份
歷史紀錄保存每次交卷結果，包含題目、選項排列、答案、開始及完成時間。每筆旁的「刪除此筆」可移除該筆成績與作答內容，確認後生效；錯題本與未完成測驗不受影響。
「題庫與備份」可新增使用者，右上選單切換，各使用者獨立保存。
使用者是本機識別，沒有帳號登入或密碼保護。
「下載備份JSON」備份所有使用者、歷史、錯題及進行中練習。
「選擇備份檔」可以在另一台裝置匯入；確認後取代所有現有資料，請先備份。
紀錄只在同一裝置、同一瀏覽器、同一網址中保存，沒有雲端同步。
清除瀏覽器資料、使用無痕模式、變更網址可能使原紀錄不可見。請定期匯出。
請避免多分頁同時作答；系統偵測其他分頁更新時會要求重新整理。
如果儲存被禁止或空間不足，畫面會明確提示失敗，不會假裝已儲存。

六、專案內容
index.html / style.css / app.js：繁體中文介面與瀏覽器儲存。
core.js：洗牌、抽題、計分、錯題及備份驗證。
bank.js / questions.json：完整題庫，兩份內容相同，分別供網頁載入與查閱。
source.pdf：原PDF，可由結果頁直接跳轉核對。
server.js / start.cmd：本機網頁啟動，不需要第三方套件。
test.js / test-results.txt：可重跑的核心測試及執行結果；執行 node test.js。
extract.py：可重建題庫，需 Python 與 pypdf；一般使用者不需要執行。
extraction-report.json / independent-audit.json：解析與交叉核對記錄。
驗證報告.txt：實際驗證範圍與已知限制。

這是可執行的本機網頁專案，未部署公用網站。可放上靜態網站主機，但紀錄仍為各瀏覽器本機儲存。

八、全題詳解（2026-10-30）
1. 上方「題庫詳解」可直接閱讀全部988題；選科目、輸入關鍵字或題號（例如q0517），按「查詢」。每頁10題，點「閱讀本題詳解」展開。
2. 勾選「只看法規差異／疑義」，可集中查看修法、原題語意疑義或引用條號問題。
3. 交卷後，逐題回顧直接顯示解題說明。既有歷史也會顯示新增詳解，不必重新作答。
4. 錯題區每題新增「閱讀詳解」，可先理解考點再練習。
5. 測驗內的選項仍然洗牌；結果上的正解字母對應當次順序。題庫詳解則以原PDF順序呈現，詳解中若提及字母也是原PDF順序。
6. 題幹、選項、標準答案及計分依據不變；外部法規只用於輔助詳解。若原題與現行法有差異，另以黃色提示說明。
7. 詳解內文隨專案打包，可離線讀取；點開官方參考來源需要網路。查核日期為2026-10-30，未來法規變動不會自動同步。
8. explanations.js為逐題詳解；explanations-report.json列出覆蓋數及已辨認疑義；node test-explanations.cjs可驗證資料完整性、顯示映射及搜尋。
9. 程式驗證不等於專業人工逐題認證；如有疑義，可由詳解的官方連結及原PDF交叉核對。
10. Cloudflare仍不需組建命令，部署命令維持npx wrangler deploy。更新時須一併上傳explanations.js、app.js、index.html與style.css，否則詳解無法載入。

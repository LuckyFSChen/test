Cloudflare Workers 部署修正版

將 wrangler.jsonc 與 .assetsignore 一起上傳到 GitHub 中放有 index.html 的資料夾。
Worker 名稱設為 test，對應本次 Cloudflare 日誌；若另建不同名稱，請同步修改 name。

Cloudflare 根目錄：包含 index.html 與 wrangler.jsonc 的資料夾。
組建命令：留空。
部署命令：npx wrangler deploy
預覽指令：npx wrangler preview

相容日期固定為錯誤日誌建議的 2026-10-23。
Cloudflare 直接提供靜態網頁，不啟動 server.js。
.assetsignore 排除本機伺服器、測試與部署輔助檔案。

若暫時無法提交設定檔，可先以命令重試：
npx wrangler deploy --assets . --name test --compatibility-date 2026-10-23

本修正已在本機檢查設定檔格式，尚未在你的Cloudflare帳號執行部署。
